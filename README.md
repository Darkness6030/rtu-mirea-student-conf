# Сервис организации студенческих конференций

Учебный проект ПР5 на Django 5.2. Сущности: конференция, студент, секция, доклад.
Секция относится к конференции, доклад связан со студентом и секцией.

## Запуск

Python 3.11 или новее:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py runserver
```

Открыть http://127.0.0.1:8000/. На Windows: `.venv\Scripts\activate`.
База данных не нужна. Bootstrap и CSS хранятся локально.

## Использование

В браузере доступны главная страница, списки и карточки:

- `/conferences/` — конференции;
- `/students/` — студенты;
- `/sections/` — секции;
- `/talks/` — доклады.

Для карточки добавьте ID: `/talks/1/`. Неизвестный адрес возвращает 404.
Для демонстрации собственной страницы 404:
`DJANGO_DEBUG=0 python manage.py runserver --insecure`.

Создание записей, подача и отмена докладов выполняются через `python main.py`.
Меню также поддерживает поиск, фильтрацию и сортировку. Приём открыт до дедлайна
включительно; переполнение секции и повторная активная заявка запрещены.
Отмена сохраняет доклад в истории и освобождает место.

Данные загружаются из `data/sample.json`. Консоль сохраняет изменения
в `data/runtime.json`, после чего веб-страницы используют этот файл.
Повреждённый файл не перезаписывается. Хранилище рассчитано на одну работающую
консоль. Можно задать путь через `python main.py --data путь.json`, а для веба —
переменной `CONFERENCE_DATA_FILE`.

По требованиям ПР5 классы и JSON сохранены: ORM, формы и авторизация пока не реализуются.

## Файлы

- `main.py` — консольное меню;
- `models/` — четыре класса предметной области;
- `services.py` — операции над объектами;
- `storage.py`, `validation.py` — JSON и проверки данных;
- `studentconf/` — настройки и корневые маршруты Django;
- `homepage/` — главная, 404 и общие функции веб-интерфейса;
- `conferences/`, `students/`, `sections/`, `talks/` — списки и карточки;
- `static/` — Bootstrap и CSS;
- `tests/` — проверки модели, хранилища и HTTP;
- `docs/` — исходные материалы;
- `results/` — отчёт и ответы на вопросы ПР5.

## Проверки и Git

```sh
pytest -q
flake8 .
python manage.py check
git log --oneline
```

46 тестов. Старые версии, журналы и снимки удалены из текущего дерева,
но сохранены в истории Git. Метки `PR1`, `PR2`, `PR3`, `PR5` обозначают исходные
этапы до упрощения. Пример просмотра: `git show PR3:main.py`.
Репозиторий локальный, удалённый адрес не настроен.
