# Сервис организации студенческих конференций

Учебный проект по дисциплине «Технологии разработки приложений на базе фреймворков».
Пользователи: студенты и организаторы студенческих научных конференций.
Сущности: конференция, студент, секция, доклад. Секция принадлежит конференции,
доклад связан со студентом и секцией. Один студент может подать несколько разных докладов.

## ПР1

Начальный сценарий проверяет срок подачи и наличие свободных мест в секции.
Последний день приёма включён в срок; полностью заполненная секция не принимает доклады.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pr1.main
pytest -v
flake8 .
```

План: ПР2 — коллекции, функции, меню и JSON; ПР3 — объектная модель;
ПР5 — отображение данных через Django. Источники требований находятся в `docs/`.
