# Контрольная точка перед ПР5

Исходная объектная версия зафиксирована коммитом `92f986a` (ПР3).
Проверены консольное меню, JSON round trip, объектные связи и регрессионные сценарии ПР2.
Все тесты ПР1–ПР3 проходят; flake8 не сообщает замечаний.

План переноса:
- `/` — назначение сервиса, навигация, сводка;
- `/conferences/`, `/conferences/<int:conference_id>/` — конференции и их секции;
- `/students/`, `/students/<int:student_id>/` — студенты и их доклады;
- `/sections/`, `/sections/<int:section_id>/` — секции, лимиты, приём докладов;
- `/talks/`, `/talks/<int:talk_id>/` — доклады, автор, секция, статус;
- неизвестный адрес или ID — HTTP 404.

Django-проект `studentconf`; приложения `homepage`, `conferences`, `students`,
`sections`, `talks`. Студент здесь — участник конференции, не учётная запись Django.
Веб-слой только читает данные, использует `storage.load_state`, `services` и классы
`models/`. Подача и отмена остаются в консоли. ORM, формы и авторизация отложены
согласно ПР5. HTML формируется через HttpResponse и общий построитель страницы.
